# Raw extracts

The raw extracts (`data/raw/`, about 560 MB) are too large for this repository. They are archived on Zenodo with the full replication package: [DOI to be added on deposit].

Download `replication_package.zip` from the Zenodo record and copy its `data/raw/` folder here, so that this folder contains `raw/`. Then run `python run_all.py` from `replication/` as described in `replication/README.md`.
